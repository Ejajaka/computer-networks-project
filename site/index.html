What the filter does

The XDP program parses IPv4 UDP and TCP SYN packets, keeps a one-second counter for each source IP, and returns XDP_DROP above the configured limit. Everything else passes to the normal Linux network stack.

What this page models

Attack rate, XDP pass/drop behavior, the dashboard verdicts, and the victim resource-load estimates. It does not execute eBPF or generate real packets.

Run the real testbed

Build the filters with make -C engine, then run bash sim/start_ui.sh for the local dashboard or sudo bash testbed/demo.sh for the CLI report.
